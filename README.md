# Eu Tenho Esse Livro

[Build 42] Mod de qualidade de vida para Project Zomboid.

Adiciona um marcador visual aos livros que você já possui na sua base.

## Recursos

- Marcar livros pelo menu de contexto
- Traduções para PT-BR e EN
- Compatível com a Build 42

## Instalação

Inscreva-se na Oficina Steam.
